# Mia Patiluna — OJT Portfolio

A responsive React + Vite + Tailwind CSS portfolio starter with custom CSS artwork and motion.

## Run locally
1. Install Node.js (LTS) if you haven't already.
2. Extract this folder and open it in VS Code.
3. Open the terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL Vite prints (usually http://localhost:5173).

## Customize before publishing
- In `src/App.jsx`, replace `your.email@example.com` with your real contact email.
- Update GitHub and LinkedIn links to your profiles.
- Adjust skills to reflect tools you actually know.
- Add screenshots or links to your actual projects. Current project thumbnails are CSS-built mockups, not screenshots of your real work.
- Update project descriptions and confirm which technologies you used.
- Optionally add a downloadable PDF resume.

## Build for deployment
Run `npm run build`; Vite creates a `dist` folder.
